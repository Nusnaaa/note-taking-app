# ADR 025 — JNI/Android selected model-resource input

Status: backend import/picker integration. Catalogue/default/uninstall/discard and real models remain open.

NativeBridge.engineImport reserves a typed consented host plan, then starts/resumes private transfer state on the optional worker. Its EngineImport exposes the stable version/transfer ID and acknowledged offset before source opening. An idle transfer returns to the same host-bound job registry entry under host-removal exclusion; close either cancels it or prevents restoration. Copy is single-use. A failed/cancelled attempt preserves private files for explicit resume, not automatic deletion or an inferred no-effect result.

HostEngineImportTransfer.prepare_with constructs the owned input inside accepted running admission and passes its exact capture/access/deadline-linked control. JNI invokes EngineInputFactory.open only there, and invokes EngineInput.read with ephemeral controls and bounded buffers. Read counts outside -1 or 1..buffer.length fail. Input/SDK resource arrays are cleared after use; the SDK factory must copy/load its verified snapshot before returning. Global input/class references support attached workers without application FindClass. Partial factory construction must clean up on throw; returned input resources retire exactly once before SQL publication. Retirement errors are contained and redacted, never treated as successful import receipts. A blocking opener/read/cleanup retains actual library ownership until it returns.

NotebookEngines adds deliberate import/resume on its existing bounded optional worker. It owns an app-private model-resources depot below noBackupFilesDir, supplies immutable transfer/staged receipts, and calls the transfer observer before opening input. EngineModelSource accepts explicit content-picker read observations, opens with mode r, checks native control while seeking the durable offset and reading, and closes both stream/asset descriptor on all owned paths. It neither persists URI permission nor uploads/fetches notebook content; resume may require the owner to select/regrant the input again. Descriptor/manifest consent precedes source callbacks. Known receipts and uncertainty semantics remain those of ADR 023.

This path copies inert, hashed bytes and never implicitly activates a model. Personal-use rights and source-publication rights still require separate review for actual packages; no proprietary SDK/weights are bundled. Byte-level JNI/R8 and API-35 simulated fixtures use app-owned synthetic data, not recognition quality or device/privacy/ART acceptance. URI-provider cooperation, malicious same-UID filesystem resistance, hard worker termination/model quotas, catalogue/recovery/default/uninstall/discard, converters and eligible real-model integration remain open.
