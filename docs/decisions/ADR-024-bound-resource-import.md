# ADR 024 — library-bound resumable engine resource import

Status: native Store/host implementation. JNI/Android picker, catalogue and import controls remain open.

Store::engine_import_plan captures only current app authority, original expiry, exact typed descriptor/total, library identity and generation after explicit consent. EngineImportPlan::begin/resume, transfer appends/copy and finish run on an optional worker. The existing private Transfer ledger now optionally records a library binding and the original consent timestamp. New imports retain a stable transfer ID before source I/O; failed/interrupted copy preserves its acknowledged offset and files for explicit resume. Bound resume validates the current library and exact manifest before opening/truncating any part. Unbound legacy ledgers require review for managed adoption; the generic legacy API remains readable. New descriptors leave room within the existing 64-KiB ledger bound, while previously readable larger legacy frames remain resumable.

Copy checks authority/control between bounded chunks and requires the declared remaining length and EOF. Finish checks control/expiry throughout both hashes, requires regular exact-length part/target files, rejects symlink targets and syncs private resource/ledger publication. No SDK is constructed. PreparedEngineImport contains only verified metadata and control; Store::commit_engine_import performs fresh app/library/generation/control checks in a callback-free SQL transaction. Repeating an identical acknowledged ID returns current staged/installed metadata without changing generation; a removed/mismatched version is never revived. A stale/cancelled commit preserves the private resumable resource, rather than deleting or acknowledging its installation. A known successful transaction stays successful if cancellation races after its final check.

Host import holders share optional count/descriptor-byte admission and capture/access epochs. Owned reader callbacks execute in a running scope; their actual destructors retire before admission/library ownership is released. Provider-owned io::Error payloads are normalized and destroyed on that worker before the scope retires, including reentrant close. Only weak host metadata capabilities enter the writer mailbox. No scope/phase lock is held across file or database I/O. Readers that ignore cancellation still retain actual ownership until they return; forced termination and global model-memory quotas are not established.

Installation state and copied bytes persist separately from notebook content and SDK readiness. The trusted host must supply an app-private OS-backup-excluded model depot, and the ledger is not a portable notebook artifact or a licence grant. No new notebook schema/EngineVersion fields, weight bundles, network fetch, model telemetry, implicit SDK load or semantic ink conversion is introduced. Deliberate real-model import still requires rights review and recorded consent; personal use and source publication are separate decisions. JNI/Android resource-backed input ownership, array-handoff/wipe acceptance, catalogue/default/uninstall/explicit discard and actual eligible models remain open.
