Review identified that the idle-cancellation guard must include the new RemovalPublishing phase. It was corrected and a deterministic test holds the private publication cell while capture cancels authority, checking that the publishing cell stays pinned until the writer exits. The manager-contention test holds the actual private manager guard and verifies the writer returns its rejection before guard release. Test watchdogs are harness bounds, not product performance claims. No failed test run is claimed for this review finding.

These tests use app-owned synthetic SDK/resources. Logical removal retains resource files and does not acknowledge every previously pinned SDK's retirement. Full-source validation is separate; JNI/Android removal, explicit discard, lease-safe disk reclamation and all eight backend gaps remain open. No device/model-quality/model-rights/hard-isolation acceptance is implied.
